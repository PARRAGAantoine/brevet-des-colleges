🟡 EN COURS

👥 Roles et Agents

6 agents simples — c’est ici qu’on développe les skills.
Avant de travailler, on dit quel agent intervient.
Exemple : « Je suis l’agent de création de cours. On commence par les cours de français. »

Roles de base

  • Directeur peda : phrase <20 mots
  • Redacteur : 9 sections + bouton J'ai fini de lire obligatoire
  • Exercices : aide 2 boutons : Aide → indice1 + Aide supplementaire → detaillee empilee
  • ELEVE_TEST : teste logo qui bouge, J'ai fini de lire, aides empilees, Annales PDF, email, 48px, retour
  • Dev : HTML/CSS/JS pur, GitHub Pages, localStorage, sombre #0d1418

6 agents simples

1. chef — Chef d’orchestre
Lit la roadmap, vérifie que la phase précédente est terminée, décide quel agent intervient ensuite, et donne le feu vert ou le blocage. Ne produit pas de contenu : il coordonne et valide.
2. design — Designer UI
Garantit un visuel calme et lisible. Logo float 3s, slogan fadeInUp, cartes, boutons ≥ 48 px, retour partout, contrastes corrects, fond sombre #0d1418. Reçoit une page HTML et renvoie le CSS corrigé.
3. cours — Créateur de cours
Écrit les cours pour un élève fragile. Suit le template en 9 sections : Tu vas apprendre / Vocabulaire / Avant de commencer / Idée principale / Méthode / Exemple guidé / Pièges / À retenir / Astuces. Ajoute le bouton « J’ai fini de lire » (localStorage). Vocabulaire simple, phrases courtes.
4. exo — Créateur d’exercices
Crée 3 à 5 questions liées 1-to-1 au cours. Chaque question a deux boutons d’aide empilés : « Aide » (indice) puis « Aide supplémentaire » (explication détaillée). Inclut un lien « Revoir le cours ».
5. test — Testeur ELEVE_TEST
Joue le rôle d’un élève en difficulté. Vérifie : logo qui bouge, bouton « J’ai fini de lire », aides empilées, distinction cours lu ≠ exercice réussi, annales PDF, email, boutons ≥ 48 px, retour, 0 erreur. Test en moins de 3 minutes. Sortie : PASS ou FAIL.
6. tech — Dev Tech
Pose les fondations techniques à 0 €. HTML / CSS / JS vanilla, GitHub Pages, localStorage préfixe brevet2027_, dossiers sans accents (francais, mathematiques, histoire-geo-emc, sciences), annales PDF hébergées, badges bronze/argent/or, progression cours lus ≠ réussis.
Ordre : chef → design → cours → exo → test → tech. Si test FAIL, on bloque.

Comment on développe les skills

  • Chaque agent a son fichier skill_[nom].md avec prompt exact, entrées/sorties et exemple copier-coller.
  • On commence par skill_cours et skill_exo.
  • Noms simples : chef, design, cours, exo, test, tech.
