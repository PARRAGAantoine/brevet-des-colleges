Phase 5 — Mode Aventure

Ajouter la couche jeu une fois le mode calme solide et utile.

Objectif de cette phase

Transformer la révision en exploration sans casser le mode calme. L’élève peut basculer entre la vue classique et la vue Aventure. La progression reste la même (localStorage).

Le Mode Aventure est le cœur de l’expérience élève. Il arrive en dernier dans la roadmap parce qu’il s’appuie sur le contenu et la progression du mode calme.

Ce qu’il faut produire

Concept

  • 4 royaumes = 4 matières
  • Chaque chapitre = un donjon
  • Cours lu = clé trouvée
  • Exercice réussi = coffre ouvert
  • Badges = loot (bois / argent / légendaire)
  • Annales = boss « Brevet Blanc »

Éléments de jeu

  • Carte simple avec zones cliquables
  • Inventaire (clés, coffres, badges)
  • Streak (torche allumée si révision quotidienne)
  • Petit PNJ de encouragement
  • Interrupteur Mode Classique / Mode Aventure

Technique

  • Stack inchangée (HTML / CSS / JS vanilla)
  • Ajout possible de phaser.min.js (~150 ko) ou pure CSS/JS
  • Réutilisation du localStorage existant
  • 0 €, pas de serveur

Règles à respecter

  • Le mode calme doit rester intact et utilisable seul
  • Pas de pression, pas de classement stressant
  • Les animations restent douces (pas de clignotement agressif)
  • La progression est partagée entre les deux modes

Checklist de fin de phase

  • Carte des 4 royaumes fonctionnelle (aventure.html)
  • Clé liée au bouton « J'ai fini de lire » (🔑 dans le donjon)
  • Coffre lié aux exercices réussis (📦 dans le donjon)
  • Badges affichés comme loot (inventaire.html : bois/argent/légendaire)
  • Boss annales accessible (lien « Brevet Blanc » en bas de chaque donjon)
  • Interrupteur Classique / Aventure opérationnel (liens croisés sur toutes les pages transverses)
  • Mode calme toujours intact (accueil à 2 boutons non modifié, vérifié en direct)
  • Test ELEVE_TEST PASS sur les deux modes (08/08/2026) — progression partagée confirmée entre les deux modes
Livrable de sortie : Mode Aventure jouable, interrupteur fonctionnel, mode calme intact, progression partagée.
Évolution (12/08/2026) : sur remarque de l'utilisateur — les clés/coffres n'avaient aucune conséquence réelle au-delà d'un changement d'icône — le Mode Aventure est devenu le mode unique et permanent de l'application (plus d'interrupteur Classique/Aventure). aventure.html a été fusionné dans matieres.html (carte des royaumes), et aventure-donjon.html a été fusionné dans chaque matieres/<matière>/index.html (donjon par matière). Les récompenses sont maintenant fonctionnelles : la clé 🔑 (cours lu) débloque réellement le bouton d'exercice sur la page du cours, et le coffre 📦 (exercice réussi) déverrouille désormais l'accès au Boss (annales) une fois tous les coffres d'un royaume ouverts — auparavant les annales étaient toujours accessibles sans condition. inventaire.html (loot bois/argent/légendaire) est conservé tel quel.
Évolution graphique (12/08/2026) : sur demande de l'utilisateur d'une "vraie carte avec de vrais graphismes", les listes/cartes plates ont été remplacées par une carte-jeu illustrée en SVG maison (aucun asset externe, 0€) : matieres.html est maintenant un chemin sinueux Départ → 4 royaumes (anneaux de progression, halos de couleur, icône couronne 👑 si royaume conquis) → Trophée final (débloqué à 90/90 coffres, relié à inventaire.html). Chaque donjon par matière affiche un chemin de niveaux façon Candy Crush (un nœud par cours : 🔒 non lu, 🔑 lu, ⭐ réussi, tracé doré une fois le nœud réussi), qui se termine par le nœud Boss verrouillé/débloqué.
Gamification approfondie (12/08/2026) : sur demande explicite de l'utilisateur ("comment gamifier encore plus ?", puis "utiliser aussi les échecs, pas que les réussites"), plusieurs mécaniques se sont ajoutées, toujours dans l'esprit "sans pression" de cette phase — aucune ne pénalise l'échec, un échec ne fait jamais reculer ni perdre quoi que ce soit :
  • XP / niveaux : calculé en direct (jamais stocké) à partir des clés (+10), coffres (+20), sans-faute (+15), royaumes conquis (+50) et streak (+5/jour, plafonné 30j) ; 6 paliers de Novice 🌱 à Légende du Brevet 🏆, affichés sur matieres.html et inventaire.html.
  • Sans-faute : nouveau flag _sansfaute par cours, posé quand les 4 questions d'un exercice sont réussies sans aucune erreur ; nœud 💎 distinct dans le donjon (au lieu de ⭐).
  • Erreurs comme donnée positive : chaque mauvaise réponse incrémente un compteur global brevet2027_erreurs_total, affiché dans l'inventaire sous "🔁 Erreurs corrigées" avec le message "chaque erreur t'a rapprochée de la réussite" — jamais présenté comme un échec.
  • Quêtes du jour : 2 objectifs quotidiens (réussir 1 puis 3 exercices) sur matieres.html, basés sur un compteur journalier remis à zéro automatiquement au changement de date.
  • Pion animé 🧍 : se positionne sur le dernier nœud atteint, sur la carte du monde et dans chaque donjon.
  • Confettis + son : à chaque exercice terminé (Web Audio généré, sans fichier téléchargé) et à chaque bonne réponse.
Techniquement, ces changements ont nécessité un patch scripté (Node, anchors texte vérifiés identiques sur les 90 fichiers avant application) des 90 pages exercices/ex1.html, qui partagent un gabarit strictement identique.
Mascottes évolutives (12/08/2026) : sur "d'autres idées pour gamifier ?" → "la mascotte qui évolue me paraît très bien", ajout d'un compagnon par royaume (🥚 Œuf → Éveil → Croissance → forme finale unique : 🦉 Lettres, 💎 Nombres, 🐉 Temps, 🦄 Éléments), visible en badge sur matieres.html et en détail dans inventaire.html. L'utilisateur a signalé que le catalogue va grandir (contrôle continu) : les seuils d'évolution sont donc en **pourcentage** de coffres du royaume (1%, 33%, 66%), jamais en nombre absolu de cours — l'ajout de nouveaux cours dans un royaume ne casse donc rien, il rallonge juste le chemin vers chaque étape.
Retour automatique + révélation (12/08/2026) : à la fin d'un exercice, un minuteur visible (5s, annulable via "Rester ici", ou accélérable via "Voir ma progression maintenant →") renvoie vers le donjon de la matière. À l'arrivée, le nœud du cours qui vient d'être réussi apparaît d'abord dans son état précédent (🔑) puis bascule avec une pulsation vers son état final (⭐/💎) après ~700ms, pendant que le pion s'estompe puis réapparaît — un repère sessionStorage éphémère (effacé après usage) fait le lien entre la page d'exercice et le donjon. Jamais de redirection silencieuse, conformément à la philosophie "sans pression" de cette phase.
