🟡 EN COURS

📋 Instructions IA

Les règles immuables du projet — pas de négociation, pas de raccourci. Phase 0 EN COURS.

🚨 Ce qui est interdit

Quelques lignes rouges qu'on ne traverse jamais, même quand c'est plus rapide :

  • Pas de Bootstrap, pas de Tailwind, pas de framework CSS. On écrit le CSS à la main. Ça reste léger, compréhensible, et ça ne casse pas.
  • Pas de backend, pas de base de données, pas d'API. localStorage uniquement.
  • Pas de données personnelles. Pas de compte, pas de mot de passe, pas de nom, pas d'adresse, pas de suivi comportemental caché.
  • Pas de publicité. Jamais. Ni bannière, ni interstitielle, ni partenariat.
  • Pas de mode clair. Uniquement le mode sombre #0d1418. Pas de choix à faire, pas de flash blanc au chargement.

💰 Budget 0€

Tout est gratuit et open-source. L'hébergement se fait sur GitHub Pages. Pas de VPS, pas de CDN payant, pas de service SaaS. Si une fonctionnalité coûte de l'argent, on la remplace par une alternative gratuite ou on l'abandonne.

Stack validée : HTML / CSS / JS vanilla, hébergé sur GitHub Pages, progression dans localStorage.

📱 Pas de données personnelles

L'élève n'a pas besoin de créer un compte. Toute sa progression vit dans son navigateur, via localStorage avec le préfixe brevet2027_. Quand il efface ses données navigateur, il perd sa progression. C'est un choix assumé : la simplicité prime sur la persistance.

Conséquence : pas de formulaire d'inscription, pas de mot de passe oublié, pas de RGPD complexe. Juste une app qui charge et qui marche.

⚡ Léger et rapide

Le site doit charger en moins de 2 secondes sur un téléphone Android d'entrée de gamme avec une connexion 3G. Pas de bibliothèque lourde, pas de polyfills inutiles. Le CSS est inline dans chaque page pour éviter une requête HTTP supplémentaire.

🏅 Badges, pas de notes

On ne met jamais de note sur 20. La motivation vient de l'accumulation, pas de la peur d'échouer. Trois niveaux :

  • Bronze — premier effort, régularité, lecture d'un premier cours
  • Argent — persévérance, série d'exercices réussis, retour sur ses erreurs
  • Or — maîtrise, tous les exercices d'un chapitre réussis, annale validée

Les seuils exacts seront ajustés à l'usage, selon la difficulté observée. L'important est que chaque badge soit mérité et visible dans la page badges.html.

🛠️ Stack technique

Du vanilla, toujours du vanilla. Pas de React, pas de Vue, pas de Angular. Trois fichiers par page maximum :

  • HTML — structure sémantique, inline CSS dans <style>
  • CSS — variables CSS pour les couleurs, flexbox et grid, boutons min 44px de haut
  • JS — vanilla ES6, localStorage pour la persistance, pas de jQuery
Thème : fond #0d1418 sombre par défaut pour tout le monde. Pas de mode clair. Pas de toggle. Moins fatigant pour les yeux, plus calme le soir.

📧 Contact vrai

Un vrai email de contact affiché en clair et cliquable : parraga.antoine@gmail.com. Il apparaît sur contact.html et éventuellement dans le footer des pages. Pas de formulaire qui collecte des données — juste un lien mailto: qui ouvre le client email de l'élève.

Pourquoi un vrai email ? Parce qu'un élève en difficulté (ou ses parents) doit pouvoir écrire s'il bloque sur un bug ou s'il veut simplement dire merci.
