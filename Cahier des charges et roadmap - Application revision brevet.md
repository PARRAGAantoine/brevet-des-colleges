# Cahier des charges et roadmap - Brevet Sprint

## Vision

Creer une application simple, offline et motivante pour preparer le brevet general en France.

L'app doit aider un eleve fragile a construire les bases, s'entrainer, reprendre ses erreurs et se rapprocher progressivement du niveau brevet.

## Principes produit

- Premier ecran tres simple.
- Pas de marketing inutile.
- Un cours clair avant les exercices.
- Des exercices coherents avec le cours.
- Des questions variees : QCM, ordre, vrai/faux, reponse ecrite.
- Les mauvaises reponses doivent etre expliquees.
- Les erreurs ne punissent pas : elles ouvrent une reprise guidee.
- Les badges motivent sur la duree, pas en quelques seances.
- L'app doit rester utilisable sans Internet.

## Perimetre V1

Inclus :

- accueil minimal ;
- seances guidees 10/20/30 exercices ;
- exercices libres ;
- progression locale ;
- anciens sujets PDF ;
- badges progressifs ;
- mode sombre ;
- PWA installable ;
- reponses ecrites simples ;
- mini-series ciblees ;
- bilan de seance.

Exclu V1 :

- compte utilisateur actif ;
- synchronisation cloud ;
- correction automatique de redaction longue ;
- IA embarquee ;
- notifications natives ;
- epreuve orale.

L'epreuve orale sera traitee tout a la fin.

## Roadmap V1 restante

1. Tester avec un eleve reel et noter les blocages.
2. Corriger les textes ou ecrans incompris.
3. Ajouter encore des reponses ecrites fermees en francais/sciences.
4. Enrichir progressivement les cours les plus courts.
5. Verifier installation PWA Android/iOS.
6. Stabiliser la V1.

## Roadmap future V2

- Connexion / identification.
- Synchronisation multi-appareils.
- Export/import progression.
- Parcours de revision plus intelligent.
- Mode parent/professeur possible.
- Epreuve orale.
- Nouvelle roadmap et nouveau contexte IA externe a partir de la V1 stabilisee.
